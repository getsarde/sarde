---

The Ocean preset is a color-only theme that changes the primary accent to a sky blue while inheriting all other defaults.

## Token Values

| Token | Light | Dark |
|-------|-------|------|
| `primary` | `#0ea5e9` | `#38bdf8` |
| `bg` | `#ffffff` | `#0f172a` |
| `text` | `#1e293b` | `#e2e8f0` |
| `font-sans` | Inter, system-ui | (inherited) |
| `font-mono` | JetBrains Mono | (inherited) |
| `radius` | `0.5rem` | (inherited) |

## Code Sample

```go
theme := sarde.Theme{Preset: "ocean"}
```

> The ocean preset is ideal for documentation sites that want a professional but approachable feel.
