The Rose preset uses a bold rose-red primary for high-energy, attention-grabbing sites.

## Token Values

| Token | Light | Dark |
|-------|-------|------|
| `primary` | `#e11d48` | `#fb7185` |
| `bg` | `#ffffff` | `#0f172a` |
| `text` | `#1e293b` | `#e2e8f0` |
| `font-sans` | Inter, system-ui | (inherited) |
| `radius` | `0.5rem` | (inherited) |

```go
theme := sarde.Theme{Preset: "rose"}
```

> The rose preset is perfect for product launches, marketing sites, and creative projects.
