The Forest preset uses a green primary accent, evoking natural growth and freshness.

## Token Values

| Token | Light | Dark |
|-------|-------|------|
| `primary` | `#16a34a` | `#4ade80` |
| `bg` | `#ffffff` | `#0f172a` |
| `text` | `#1e293b` | `#e2e8f0` |
| `font-sans` | Inter, system-ui | (inherited) |
| `radius` | `0.5rem` | (inherited) |

```go
theme := sarde.Theme{Preset: "forest"}
```

> The forest preset works well for developer tools, sustainability projects, and nature-focused sites.
