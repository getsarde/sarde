The Clean preset is a full-identity theme with teal accents, rounded corners, and the Plus Jakarta Sans typeface.

## Token Values

| Token | Light | Dark |
|-------|-------|------|
| `primary` | `#0f766e` | (inherited) |
| `bg` | `#ffffff` | `#042f2e` |
| `bg-surface` | `#f0fdfa` | `#0f3d3c` |
| `text` | `#134e4a` | `#ccfbf1` |
| `text-muted` | `#5eead4` | `#5eead4` |
| `border` | `#ccfbf1` | `#115e59` |
| `font-sans` | Plus Jakarta Sans | (inherited) |
| `font-mono` | Fira Code | (inherited) |
| `radius` | `0.75rem` | (inherited) |

```go
theme := sarde.Theme{Preset: "clean"}
```

> The clean preset is ideal for SaaS products, startups, and modern web applications.
