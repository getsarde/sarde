Tailor the look and structure of a Sarde site beyond presets and design tokens.

- [Layouts and Templates](/customization/layouts-and-templates/) covers layout
  types, the template overlay resolution chain, and creating custom template
  variants.
- [Using Themes](/customization/using-themes/) covers installing, activating,
  and managing theme packages.
- [Creating a Preset](/customization/creating-a-preset/) defines a named set
  of token values a site can switch to with one config line.
- [Creating a Theme](/customization/creating-a-theme/) walks through building
  a theme from scratch.
