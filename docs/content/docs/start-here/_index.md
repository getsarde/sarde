Read these pages in order to learn what Sarde is, build a first site, write your own pages, and publish them.

1. [What Is Sarde](/start-here/what-is-sarde/) explains what Sarde does, what a build produces, which kinds of sites it suits, and the tradeoffs that come with it.
2. [Installation](/start-here/installation/) installs the `sarde` command on macOS, Linux, or Windows.
3. [Getting Started](/start-here/getting-started/) creates a site, previews it locally, adds a page, and produces a production build.
4. [Write Your First Pages](/start-here/writing-your-first-pages/) turns that site into your own: Markdown, callouts, images, links, sidebar order, sections, and the homepage.
5. [Core Concepts](/start-here/core-concepts/) explains the model behind it: content and URLs, frontmatter, collections, configuration, and themes.
6. [Deploying](/start-here/deploying/) publishes the site to GitHub Pages, Netlify, Cloudflare Pages, Vercel, or another host.

After the site is live, [Updating Sarde](/start-here/updating-sarde/) covers installing new releases with `sarde update`.
