Highlights wrap text in a `<mark>` element with a yellow/amber background. The color adapts to light and dark themes.

## Basic Usage

```md
==highlighted text==
```

Use `==` on both sides of the text to highlight:

```md
The most important setting is ==`site.url`==, which must be set before building for production.
```

Renders as: The most important setting is ==`site.url`==, which must be set before building for production.
