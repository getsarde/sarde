Extensions add custom syntax to Markdown. All extensions are built into the
Sarde binary and active by default.

Read [Using Extensions](/extensions/using-extensions/) for the block (`:::`)
and inline (`:name[]`) syntax conventions, nesting rules, and attributes.

**Block extensions** handle multi-line containers: [Aside](/extensions/aside)
(callouts), [Tabs](/extensions/tabs), [Cards](/extensions/cards),
[Steps](/extensions/steps), [Accordion](/extensions/accordion),
[Details](/extensions/details), [File Tree](/extensions/file-tree),
[Gallery](/extensions/gallery), [Timeline](/extensions/timeline),
[Columns](/extensions/columns), [Badge Group](/extensions/badge-group),
[Link Button Group](/extensions/link-button-group), and more.

**Inline extensions** handle text-level markers: [Icon](/extensions/icon),
[Kbd](/extensions/kbd), [Highlight](/extensions/highlight),
[Annotation](/extensions/annotation), [Spoiler](/extensions/spoiler), and
[Copy Text](/extensions/copy-text).
