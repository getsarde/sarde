---
title: Welcome
description: "Sarde is a static site generator that turns a folder of Markdown into a finished website, ideal for documentation, course materials, and blogs"
---

Drop a page into `content/docs/` and it appears in the sidebar, indexed for search. The navigation mirrors the folder tree, so organizing your files is organizing your site. There is nothing else to wire up.

## Try it

```sh
sarde new site my-site
cd my-site
sarde dev
```

Open `http://localhost:4727` to see the site. Continue with [Getting Started](/docs/start-here/getting-started/) for the full walkthrough, or read [What Is Sarde](/docs/start-here/what-is-sarde/) for the model behind it.
