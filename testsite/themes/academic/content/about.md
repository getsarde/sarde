The Academic preset combines a navy blue primary with Merriweather serif typography for scholarly, research-oriented sites.

## Token Values

| Token | Light | Dark |
|-------|-------|------|
| `primary` | `#1e40af` | (inherited) |
| `bg` | `#fefefe` | `#1c1917` |
| `bg-surface` | `#f5f3ef` | `#292524` |
| `text` | `#1c1917` | `#e7e5e4` |
| `text-muted` | `#57534e` | `#a8a29e` |
| `border` | `#d6d3d1` | `#44403c` |
| `font-sans` | Merriweather, Georgia, serif | (inherited) |
| `font-mono` | Source Code Pro | (inherited) |
| `radius` | `0.25rem` | (inherited) |

```go
theme := sarde.Theme{Preset: "academic"}
```

> The academic preset is designed for university course sites, research documentation, and scholarly publications.
