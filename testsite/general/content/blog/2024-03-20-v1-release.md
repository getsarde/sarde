After three months of beta testing, Velox v1.0 is now generally available.

:::tip
Upgrading from beta? Check the migration guide below for breaking changes.
:::

## Release Timeline

:::timeline

== January 2024

**Alpha release.** Core routing engine with radix tree matching and path parameters. Initial benchmarks showed 10x improvement over regexp-based routers.

== February 2024

**Beta release.** Middleware system, plugin API, and the first community contributions. 47 issues closed in 30 days.

== March 2024

**v1.0 stable.** Full test coverage, comprehensive documentation, and production deployment guides. Adopted by three companies for production APIs.

:::

## Breaking Changes

| Change | Migration |
|--------|-----------|
| `Handle()` removed | Use `GET()`, `POST()`, etc. |
| `Context.Param()` returns `string` | Previously returned `(string, bool)` |
| Middleware signature changed | See middleware docs |
