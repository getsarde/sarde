Create a simple HTML page with a heading, paragraph, and an image. Replace this with your assignment instructions.

## Requirements

- Use semantic elements
- Include at least one image
- Validate with the W3C validator

## FAQ

:::accordion
:::details[Can I use a CSS framework?]
Not for this assignment. Use plain HTML so the structure is your own.
:::
:::details[Where do I find an image?]
Use any image you have the right to share, or a free stock photo.
:::
:::details[How do I submit?]
Zip the project folder and upload it to the course platform.
:::
:::
