## Installing Go

:::tabs
== Windows

Download the installer from [go.dev/dl](https://go.dev/dl/) and run it.

== macOS

```bash
brew install go
```

== Linux

```bash
sudo apt install golang-go
```
:::

:::note
Run `go version` in a new terminal to confirm the installation worked.
:::
